# Contributing

## Releasing

This script is published on [GreasyFork](https://greasyfork.org/en/scripts/481045-skroutz-sponsored-remover). GreasyFork auto-syncs from this repo when changes are pushed to `master`.

1. Bump `@version` in `src/skroutz_sponsored_remover.user.js`
2. Commit and push to `master`
3. GreasyFork picks up the change shortly after (webhook + GitHub raw cache delay)

Sync source URL:

```
https://github.com/sotoskprs/skroutz-sponsored-remover/raw/master/src/skroutz_sponsored_remover.user.js
```
